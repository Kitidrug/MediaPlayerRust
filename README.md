# GStreamer Media Player (Rust)

Высокопроизводительный кроссплатформенный медиаплеер на **Rust (2021 edition)** с мультимедийным бэкендом на **GStreamer (playbin / appsink)** и графическим интерфейсом на **egui / eframe**.

---

## Ключевые возможности и улучшения

### 1. Поддержка множественных аудиодорожек (разные озвучки в одном файле)
- **Детальное автоопределение озвучек**: извлечение названий релиз-групп и студий дубляжа (Дубляж, LostFilm, Red Head Sound, HDRezka, Кубик в Кубе), кода языка (`[RUS]`, `[ENG]`), количества аудиоканалов (`5.1`, `7.1`, `Stereo`), кодека (`AC3`, `E-AC3`, `AAC`, `DTS`, `FLAC`, `Opus`) и битрейта.
- **Динамическое переключение на лету**: через удобный выпадающий список в панели управления или **быстрой клавишей `A`** с мгновенным OSD-уведомлением на экране видео.
- **Мгновенное переключение без задержек**: поток аудио переключается атомарно внутри GStreamer без остановки или сброса видеокадра.

### 2. Полноценный интерактивный таймлайн для видео
- **Кастомный рендеринг**: динамическое плавное увеличение высоты полосы прогресса при наведении курсора.
- **Hover Preview (Всплывающий предпросмотр времени)**: при наведении мыши в любую точку таймлайна над курсором отображается стильный бейдж с точным временем (`01:24:05`) и вертикальный маркер.
- **Click-to-Seek и Drag-to-Scrub**: мгновенный переход в точку клика и плавное перетаскивание ползунка без дрожания интерфейса.
- **Переключаемый таймер**: клик по общему времени справа переключает режим отображения между *общей длительностью* (`01:45:20`) и *оставшимся временем* (`-00:32:15`).

### 3. Оптимизация производительности и плавность
- **Разгрузка UI-потока (Zero Lag)**: распаковка байтов RGBA в `egui::ColorImage` вынесена целиком в фоновый поток декодирования GStreamer и передается в очередь через легковесный `Arc`. Главный поток GUI больше не тратит время на проход по массивам пикселей.
- **Устранение лишних аллокаций**: размер очереди кадров ограничен 2 буферами со стратегией `drop(true)`, предотвращая скапливание кадров и просадки FPS.

### 4. Современный премиальный дизайн (Dark Glass Aesthetics)
- Глубокая темная палитра (`Obsidian` & `Deep Slate`), стеклянный акцент Indigo (`#4f46e5` / `#6366f1`).
- Обновленные закругленные кнопки управления, индикатор паузы на видео, прогресс громкости в процентах и OSD-тосты с анимацией затухания.
- Список серий / плейлист для удобного просмотра сериалов с поиском и автовоспроизведением.

## Горячие клавиши

| Клавиша | Действие |
| :--- | :--- |
| **Space** / **K** | Воспроизведение / Пауза |
| **A** | **Переключение озвучки / аудиодорожки** |
| **S** | Переключение субтитров |
| **Влево** / **Вправо** (или **J** / **L**) | Перемотка назад / вперед на 5 секунд |
| **Shift + Влево** / **Вправо** | Перемотка на 10 секунд |
| **Ctrl + Влево** / **Вправо** | Перемотка на 30 секунд |
| **Вверх** / **Вниз** | Громкость + / - 5% |
| **M** | Без звука (Mute / Unmute) |
| **[** / **]** | Уменьшить / увеличить скорость воспроизведения |
| **Backspace** | Сбросить скорость на 1.0x |
| **F** / **F11** / **Двойной клик** | Полноэкранный режим |
| **N** / **P** | Следующая / Предыдущая серия |

# Сборка и запуск
